# Adrobot: интерфейс для Keitaro

Тестовое приложение на Python, FastAPI и SQLAlchemy. Оно создаёт тестовую кампанию и позволяет редактировать офферы потоков с локальным сохранением черновиков.

**Статус:** приложение проверено автоматическими тестами и на предоставленном тестовом сервере Keitaro. Проверены создание кампании с двумя потоками, загрузка, добавление, удаление и восстановление оффера с публикацией изменений. В браузере проверены загрузка кампании, удаление оффера из черновика, пересчёт долей и отмена изменения.

## Возможности

- Создание кампании с доменом, группой, источником и двумя потоками: фильтр страны с переходом на Google и поток с выбранным оффером.
- Загрузка существующих потоков, включая потоки без офферов.
- Добавление, удаление и восстановление офферов в локальном черновике.
- Пересчёт целочисленных долей до 100% с сохранением закреплённых долей.
- Отмена черновика и отправка изменений в Keitaro отдельной кнопкой.
- Проверка, что список офферов в Keitaro не изменился после загрузки: при конфликте публикация блокируется.
- Если оффер удалён непосредственно в Keitaro, повторная загрузка помечает его удалённым и сохраняет возможность восстановления.

Для защиты общего тестового сервера создание и публикация ограничены кампаниями с именем `test_karklins_...`. Приложение предназначено для локального использования, без публичного доступа.

## Установка и запуск в Windows

Нужен Python 3.10 или новее и доступ к Keitaro Admin API.

```powershell
python -m venv .venv
.\.venv\Scripts\Activate.ps1
python -m pip install -r requirements.txt
Copy-Item .env.example .env
```

Откройте `.env` в текстовом редакторе и укажите адрес тестового Keitaro и выданный API-ключ. Файл `.env` не включается в Git. Не добавляйте в репозиторий ключи, пароли, локальные базы и данные тестового сервера.

```powershell
python -m app.db
python -m uvicorn app.main:app --host 127.0.0.1 --port 8000
```

Откройте `http://127.0.0.1:8000`. Выберите существующие домен, группу, источник и оффер, затем создайте тестовую кампанию. Для редактирования выберите кампанию и нажмите **Fetch streams**.

## Миграция базы данных

Команда `python -m app.db` выполняет начальную миграцию схемы и сохраняет её версию в таблице `schema_version`. Запускать команду повторно безопасно. По умолчанию создаётся локальная база SQLite `adrobot.db`. Её расположение можно изменить через `DATABASE_URL` в `.env`. При запуске приложения первоначальная схема также проверяется автоматически.

## Тесты

```powershell
python -m unittest discover -s tests -v
```

Тесты используют изолированную базу в памяти и имитацию API. Они проверяют создание двух потоков, пересчёт весов, закрепление, черновик и отмену, публикацию, восстановление и конфликт при внешнем изменении. Настоящему серверу запросы при этих тестах не отправляются.

## Ограничения

- Публичная авторизация и многопользовательское разграничение доступа не реализованы. Запускайте сервис только на `127.0.0.1`.
- Доли округляются до целых процентов; при трёх незакреплённых офферах они составят 34%, 33% и 33%.
- Если создание кампании прервалось после ответа сервера, приложение сообщает её ID для ручной проверки. Повторять создание без проверки не следует.
- Повторная загрузка запрещена, пока есть неопубликованный черновик. Сначала опубликуйте или отмените изменения.
- Этот проект не публикует рекламу и не создаёт объявления: он управляет тестовой конфигурацией потоков в трекере.
